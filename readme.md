# 🧩 LLD Practice Repo

This repo contains my daily practice of **Low-Level Design (LLD)**, some of the best and most asked LLD problems for software engineer interviews.

This repo helps me in building a strong foundation in designing **scalable, maintainable and extensible systems using object-oriented programming principles**.

-----
## The Goal

This is a repository to practice LLD interview problems and continue building the system design thinking.

The idea is simple yet powerful. We want to improve our system design and design patterns knowledgebase.

Some examples of the system that are in this repo:

- Parking System
- Library Management System
- Snake and Ladders
- ...

---

## My Approach

Considering that we are preparing these problems, I have implemented and designed a very simple and evolving design.

The key note is that these are basic designs and need to be improvised.

Some of the things that I want to do would be:

- Refactor the  designs
- Implement design patterns
- Handle more edge cases
- Any new feature that would be required


---

## Why is this important?

These problems are best and most asked low-level design problems for software engineer role.

-----
## How I study LLD?

I believe in the power of practice and building skills for such problems through practice, learning and iterating.

That is why I liked this repo. You could learn a lot from it.
